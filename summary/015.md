# 015 — Terminal Password Detection and Agent Safety Protection

- Status: Captured (conclusions recorded in *-docs)
- Date: 2026-09-13 18:18
- One-liner: Detect password input from echo-off state and build graded interaction, command review, redaction, and injection defenses.
- Background / Problem:
  - Once agents can write to terminals and spawn processes, human eyes are no longer the only safety net, exposing privilege-escalation tricks, confused deputies, credential leaks, and irreversible damage.
  - Regex-based detection of passwords and confirmation prompts suffers from multilingual coverage, false positives, and forged output.
  - Safety confirmations must preserve automation efficiency.
- Key conclusions / Decisions:
  - Treat terminal echo-off state as the password signal rather than text matching; echo-off means a sensitive credential request.
  - Grade interaction into three levels: no-echo sensitive credentials block agent involvement and require human input; high-risk confirmations block auto-reply and require human authorization; safe routine interactions allow policy-based auto-reply.
  - During no-echo periods, cut off agent writes at the dispatch layer, raise a safety overlay for humans, and pass input straight to the kernel without snapshots or records.
  - Routine confirmations auto-proceed only with causal origin, initially authorized intent, and no irreversible risk, leaving an audit log.
  - Review commands at the syntax-tree level before execution across four tiers — read-only, development, local reset, destructive plus external — for allow, audit, or block; hard-deny pipes into interpreters, privilege escalation, sensitive directory traversal, recursive deletion, and raw disk writes.
  - Record no scrollback during no-echo periods; redact keys and high-entropy strings before output enters context; mark all terminal output as an untrusted observation plane and lock anti-injection rules into the system prompt.
  - Divide responsibilities so the core owns state sensing, input routing, semantic partitioning, and safe rendering, the AI base layer owns redaction, auditing, and context assembly, and Lua owns interaction decisions and authorization UI.
