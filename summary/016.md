# 016 — Modifier Key Choice and Spatial Beacon Action Engine

- Status: Captured (conclusions recorded in *-docs)
- Date: 2026-09-13 18:38
- One-liner: Choose Alt as the primary modifier with a leader-key modal, using spatial badges for one-handed panel and semantic actions.
- Background / Problem:
  - Traditional multi-key chords strain fingers, and terminals struggle to separate shell-bound control keys from host shortcuts.
  - In-text jump tools cannot cover multiple panels, folded output, and cross-panel controls.
  - One-handed operation and consistent cross-platform experience need support.
- Key conclusions / Decisions:
  - Select Alt as the default primary modifier; Ctrl collides with line-editing signals, system keys are taken by the desktop, and Shift cannot modify alone.
  - Assign frequent single-step actions to modifiers and the spatial-beacon modal to a leader key; default to Alt plus Space with auto-exit on timeout, reserve an alternative for Windows, and allow user remapping.
  - Cover the whole workspace with the spatial engine, rendering letter badges that support jump, fold, focus-input, and script-dispatch actions.
  - Fold output around semantic command blocks with millisecond switching; declare script actions in Lua, able to spawn system processes or switch views.
  - Pin badges to the left-hand home key area by default, with single-key reach for few targets and same-side double-key overflow for many targets, avoiding two-handed stretches.
  - Keep rendering and input interception in the core within millisecond budgets, with badge placement rules and hit callbacks as Lua policy.
