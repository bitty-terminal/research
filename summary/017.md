  - Keep AI terminal-friendly rather than agent-centric, and add generic primitives before generic abstractions are missing; gate new open questions by admission rules favoring blockers for the current milestone or questions explaining implementation evidence.
  - Converge next on automated canonical snapshot updates, a compatibility matrix, frozen workspace invariants, panel RFC promotion, plugin ecosystem crossing, and vertical slices validating AI abstractions.
