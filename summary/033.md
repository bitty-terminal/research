# 033 — Unified Multimodal Model Abstraction

- Status: Captured (conclusions recorded in *-docs)
- Date: 2026-09-15 13:40
- One-liner: Unifies task lifecycles and asset representation without forcing a single request shape across modalities.
- Background / Problem:
  - Whether image, video, and audio belong in the same text-completion interface is disputed.
  - Vendor interfaces are only partly unified, and video generation is mostly asynchronous.
  - Large binary payloads can easily blow up agent context and storage.
- Key conclusions / Decisions:
  - Unify the model catalog, capability queries, routing, and task lifecycles while keeping per-modality request structures independent.
  - Requests use a common outer envelope plus per-task enums, avoiding a giant parameter struct.
  - A unified generation-task state machine carries unknown-state reconciliation semantics to avoid duplicate charges after disconnects.
  - Outputs are uniformly asset references; context keeps only references instead of inlining large content.
  - Agents emit only start, progress, and completion events; presentation is decided by terminal panels and plugins.
  - Script plugins handle only orchestration and UI mapping; heavy transport and binary lifecycles sink into the host.
  - Aggregate provider plugins may cover a batch of models at once; the management surface grows into a model hub.
